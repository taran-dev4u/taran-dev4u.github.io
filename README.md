## 📌 Executive Summary

This repository contains the source code for the personal software engineering and AI/ML portfolio website of **Taran Mamidala** (MS in Computer Science, University at Buffalo).

Live Production URL: **[https://taran-dev4u.github.io](https://taran-dev4u.github.io)**

---

## 🚀 Key Features

- **Interactive Architecture:** React 18, TypeScript, Tailwind CSS, Lucide Icons, and Framer Motion animations.
- **Showcase Sections:** Open-source contributions (AquaScope, FlexMeasures, timely-beliefs, NeMo Automodel), academic research projects, enterprise RAG applications, technical skills matrix, and interactive resume viewer.
- **Automated Intelligence:** Includes an interactive **H-1B Employer Intelligence Tool** and **SWE/AI Job Search Portal** with live data filtering.

## 🛠️ Local Development

```bash
git clone https://github.com/taran-dev4u/taran-portfolio.git
cd taran-portfolio
npm install
npm run dev
```
