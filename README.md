# Portfolio Application

Personal software engineering and AI portfolio website built with React 18, TypeScript, Tailwind CSS, and Vite.

Live site: [https://taran-dev4u.github.io](https://taran-dev4u.github.io)

## Features

- **Project Showcases:** Open-source contributions, computer vision systems, deep learning models, and enterprise applications.
- **Interactive Tools:** Built-in H-1B employer analytics explorer and SWE/AI job search tool.
- **Responsive Design:** Dark/light themes, mobile navigation, and optimized assets.

## Local Development

```bash
npm install
npm run dev
```
